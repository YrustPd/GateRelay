# Support

Use GitHub issues for reproducible bugs, focused feature requests, configuration help, deployment/systemd help, and documentation improvements.

Before posting, remove:

- Proxy username/password
- Full subscription tokens
- Private TLS keys
- Sensitive production logs

For security vulnerabilities, do not open a public issue. Follow [SECURITY.md](SECURITY.md).

GateRelay is a small open-source project. Support is best-effort and works best when reports include version, OS, architecture, sanitized config snippets, and sanitized logs.
